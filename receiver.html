💻 部署與使用說明
  1. 在這台電腦上運行服務：打開命令提示符，進入項目文件夾，執行 npm install && npm start
  2. 在路由器上設置端口映射：將外網8443端口映射到本機的8443端口
  3. 查詢你的固網公網IP，可以在百度搜索「IP」即可看到
  4. 手機連接移動網絡（不要連同一WiFi），打開 https://你的公網IP:8443/sender.html
  5. 手機端點擊連接，授予麥克風權限，即可實時傳輸音樂
  6. 電腦端點擊「啟動接收並播放」，即可聽到無壓縮音頻
⚠️ 重要提示：由於瀏覽器安全限制，手機端必須使用HTTPS才能訪問麥克風。首次訪問時會提示證書不受信任，這是因為我們使用了自簽名證書，請點擊「高級」→「繼續訪問」即可，不影響音頻質量和安全性。

🎵 音頻質量說明：
完全未經任何壓縮編碼，原始16-bit PCM數據直傳，音質等同CD級別以上，沒有任何編碼損耗，適合傳輸高保真音樂。自動適配手機原生採樣率（通常48kHz），立體聲傳輸，碼率約1.5Mbps，移動網絡完全可以勝任。
